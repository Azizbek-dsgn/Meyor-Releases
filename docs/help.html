Yordam

Mac “Hustler ochilmadi” deyapti

Bu sertifikatsiz bepul dasturlar uchun odatiy. System Settings → Privacy & Security → “Open Anyway”. Rasmli qo‘llanma: O‘rnatish sahifasi.

Windows “isn't commonly downloaded” yoki “protected your PC” deyapti

Edge’da ⋯ → Keep → Keep anyway; SmartScreen’da More info → Run anyway.

Swible Premiere’da ko‘rinmayapti

Hustler’da Swible o‘rnatilganini tekshiring, Premiere’ni qayta oching: Window → Extensions → Swible.

AI ulanmayapti

Hustler → Sozlamalar → AI yordamchi: “O‘rnatish”, keyin “Kirish” (akkauntga kiring), so‘ng “Ulash”.

Avto montaj mening uslubimda ishlashi uchun

Montaj qoidalaringizni SKILL.md fayli bilan papkaga yozing va Documents’ga qo‘ying (yoki Hustler → Skill’lar). Swible AI ularni o‘zi o‘qiydi.

Tempass vaqtni yozmayapti

Swible paneli Premiere/After Effects’da ochiq va loyiha saqlangan bo‘lsin. Tempass sozlamalarida avtomatik kuzatish yoqilgan bo‘lsin.

Ma’lumotlarim qayerda?

Video, ovoz va matnlar — faqat kompyuteringizda. Akkaunt yozuvi shifrlangan, uni faqat admin ochadi (Maxfiylik sahifasi). Boshqa kompyuterga o‘tkazish: Hustler → Sozlamalar → Sinxronlash.

Akkauntim bloklandi

Sababi Hustler’da ko‘rsatiladi. Xato deb o‘ylasangiz: Telegram @Abdulaziz_kbv.

Bepul AI qanday ishlaydi?

Hustler → Sozlamalar → AI yordamchi → Bepul AI: Ollama’ni o‘rnating, kompyuteringizga mos modelni yuklang (hajmi va RAM ko‘rsatiladi). Swible’da “Bepul AI · kompyuterda”ni tanlang. Obuna va internet kerak emas, lekin kompyuter kuchidan foydalanadi.
