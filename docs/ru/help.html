Помощь

Mac пишет «Hustler не открыт»

Так бывает у бесплатных программ без сертификата. System Settings → Privacy & Security → «Open Anyway». Инструкция с картинками — на странице установки.

Windows пишет «isn't commonly downloaded» или «protected your PC»

В Edge: ⋯ → Keep → Keep anyway; в SmartScreen: More info → Run anyway.

Swible не виден в Premiere

Проверьте, что Swible установлен в Hustler, перезапустите Premiere: Window → Extensions → Swible.

AI не подключается

Hustler → Настройки → AI-помощник: «Установить», затем «Войти», затем «Подключить».

Чтобы автомонтаж работал в моём стиле

Опишите свои правила в папке с файлом SKILL.md и положите в Documents (или Hustler → Скиллы). Swible AI прочитает их сам.

Tempass не считает время

Панель Swible должна быть открыта в Premiere/After Effects, проект сохранён, а в Tempass включено автоматическое отслеживание.

Где мои данные?

Только на вашем компьютере. Перенести на другой: Hustler → Настройки → Синхронизация.

Инструкция по установке (с картинками) →

Всё работает на вашем компьютере. Видео, звук и текст никуда не отправляются.
